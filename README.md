# TaskFlow

TaskFlow is a simple task management web application created as a university project.

The application allows users to create and organize tasks, track their progress, view deadlines in a calendar, and check productivity statistics.

## Features

- Create new tasks
- Edit and delete tasks
- Mark tasks as completed
- Set task priority: Low, Medium, High
- Set categories and due dates
- Search tasks by name or category
- Filter tasks by status
- Calendar with task deadlines
- Task statistics
- Completion progress
- Priority breakdown
- Dark mode
- Data saving with LocalStorage

## Technologies

- HTML
- CSS
- JavaScript
- LocalStorage

## Pages

### Dashboard

Displays task statistics and the current task list.

### My Tasks

Allows users to manage, search, and filter all created tasks.

### Calendar

Displays tasks according to their due dates.

### Statistics

Shows total tasks, completed tasks, tasks in progress, completion rate, and priority statistics.

### Settings

Allows the user to switch between light and dark mode.

## Data Storage

TaskFlow uses browser LocalStorage to save tasks and application settings.  
The data remains available after the page is refreshed.

## Project Purpose

The project was created to practice front-end web development and working with HTML, CSS, JavaScript, DOM manipulation, and LocalStorage.
